Fixes found by reading 0.1.0 closely. Nothing changes in how you use TrueBrain.

**Fixed**
- Making proposals twice in one day said "-1 proposals" after redoing all the work. It now opens today's note and says so.
- Disabling the plugin left timers running that could still write the AI index. They stop now.
- The first AI index after Obsidian starts showed heat 0 for every note. It now has real heat.
- The usage log (`.truebrain/usage.jsonl`) only ever grew, and heat re-reads all of it. Once a day it is trimmed to the 400 days heat looks at.
- Unpacking a file with no extension beside a file of the same name cut off its last character.
- The "max proposals" settings can now be 0, to turn a section off.

**Faster** in a 4,000-note vault: heat about twice as fast, Find about three times as fast per keystroke.

**For developers**
- Builds are identical on every machine. A Windows checkout used to produce a different `main.js`.
- `node build.js --check`, CI on every push, and releases published from a version tag.
- 46 tests, up from 33.
